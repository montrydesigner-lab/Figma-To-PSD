# 安装包

最新推荐：[Montry-PSD-PSB-Bridge-0.1.6.zip](Montry-PSD-PSB-Bridge-0.1.6.zip)。此公开ZIP包含已测试插件、源码及说明。为排除本机路径，仅交接文档与包内清单发生变化，插件源码和编译产物字节不变；此ZIP使用独立校验值，原Library交付包保持不变。

完整解压，在 Figma 桌面版开发插件入口选择 manifest.json，并保留 dist。确认 LOCAL / 0.1.6。[展开安装文件](Montry-PSD-PSB-Bridge-0.1.6/) 也必须整目录下载。

[SHA-256](SHA256SUMS-0.1.6.txt) · [发布验证](RELEASE_VALIDATION-0.1.6.json) · [交接](../HANDOFF-0.1.6.md)

0.1.6 支持多文件串行队列，不创建额外合成对比画板；单文件上限1.5 GB，插件需保持打开。真实 Figma、大文件和长队列压力测试未执行。
