# Montry · PSD / PSB Bridge 0.1.4 安装包

用途：将 PSD / PSB 导入 Figma，不是从 Figma 导出 PSD。

完整解压后，在 Figma 桌面版的 Plugins → Development → Import plugin from manifest… 中选择本文件夹的 manifest.json。请保留同级 dist 文件夹及内部两个文件，不能只下载 manifest.json。无需安装 Node.js 或重新构建。

插件代码与原 0.1.4 归档一致。本次仅整理归档，未重新运行测试，未进行真实 Figma 功能验收。完整源码、历史测试报告、使用说明与兼容性限制见仓库「源代码」目录。

第三方许可证见 THIRD_PARTY_LICENSES.txt。
