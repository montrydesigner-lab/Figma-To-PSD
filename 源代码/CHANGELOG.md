# 0.1.6

基于已交付 0.1.5 的独立副本，加入一次多选／拖放、并发度 1 的自动串行导入队列。

- 轻量逐文件预检，未开始的文件不解码；显示文件状态、总进度与当前进度。
- 文件级失败后继续，结束汇总，单独重试失败项。
- 区分取消当前和停止全部；只有宿主确认本文件结束／回滚后才启动下一份，无法确认时暂停。
- 唯一会话隔离迟到消息，批次固定目标页，文件名安全命名及重名编号。
- 本批字体映射复用，新的缺失字体暂停待确认，保留原字体搜索。
- 逐文件释放解析树和转换结果，报告改为精简批次摘要；画布内容及 Figma 缓存仍累积。
- 保留 0.1.5 不生成额外对比画板的行为及全部原转换模块。

仅在插件打开期间运行。每文件 1.5 GB 阈值未提高，也不表示所有阈值以下文件都可成功。验证范围和未验证边界见 TEST_REPORT.md。

# 0.1.5

基于 0.1.4 当前源码，仅取消额外对比展示画板的导入。

- 导入后保留「可编辑」画板及源内容，不再新增「原始合成预览」。
- 移除「保留原稿参考图」选项；原图片、文字备份、多画板和现有 Figma 内容保留。
- 保留字体搜索、× 清除、隐藏层选项、图像效果和原转换规则。
- UI、主程序和交付包统一标为 0.1.5。批量导入未加入本版。

完整解压后，在 Figma 桌面版开发插件入口选择本文件夹的 manifest.json；dist 必须一同保留，无需安装 Node.js。此包包含源码、编译产物、小型合成测试文件和测试记录。

构建、类型检查、完整 npm test 和本地浏览器模拟测试通过；真实 Figma 导入未验证。后续 0.1.6 串行批量导入见 HANDOFF-0.1.6.md。
